# ThumbAI MVP

## Запуск

1. Установи Node.js 18+.
2. Открой терминал в этой папке.
3. Выполни:

```bash
npm install
```

4. Создай файл `.env` на основе `.env.example` и вставь свой OpenRouter API key:

```env
OPENROUTER_API_KEY=sk-or-v1-...
SITE_URL=http://localhost:3000
```

5. Запусти:

```bash
npm start
```

6. Открой http://localhost:3000

## Важно

`/api/dev-plan` — только демонстрация тарифов. В настоящем стартапе его нужно убрать и менять план только после подтверждения оплаты на сервере.

Бесплатный роутер OpenRouter выбирает доступную бесплатную модель автоматически. Бесплатные модели и их доступность могут меняться.
